# Selective sharing

Only 20 observed rack records are published, in sample_data.csv. Full development and new-match observation tables, predictions, source reconciliation files, review histories and original workbooks remain private. The public HTML contains only aggregate summaries and model coefficients; it does not contain a full observed-record array or a service that returns private records.

Reports share aggregate rates, uncertainty intervals and model scores. The 384 model-test cases are generated feature combinations, not observed racks, and contain no actual winner labels or rack IDs. Model coefficients and browser code are intentionally public and can be copied.

The old exact-match support-count feature is removed. Hiding a download button alone would not have removed embedded records; both the record payload and legacy download files are absent from the current static assets. Earlier owner-private source/deployment history has not been erased and must not be republished. Use this fresh selective package, not old bundles or old Git history.

No Excel workbook or personal document-author metadata is included. Originals remain private and unchanged. The current website audience remains owner-private until explicitly changed.
