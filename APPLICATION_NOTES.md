# Application wording

Role: Project Creator and Data Analyst

Project: Pool Break Analytics

## Short activity description (116 characters)

Created a 509-rack pool dataset; evaluated win-probability models on new matches and built an interactive dashboard.

## Longer description

Designed a 9-ball break study and manually collected 500 source observations, retaining 488 distinct development racks after deduplication. Defined coding rules, reviewed a 50-rack random sample and resolved priority issues. Evaluated models with match-grouped cross-validation, then tested a frozen model on 21 additional racks. Built an interactive dashboard and documented both findings and limitations. AI assisted coding and implementation.

## Talking points

- Why the project: turn a recurring question from playing and watching pool into a measurable study.
- What I contributed: question design, data collection, rule definitions, label review and interpretation.
- What surprised me: more pocketed balls did not produce a simple increasing win-rate pattern; a fuller model did not beat the foul-only model on accuracy.
- What I learned: compare with simple baselines, keep entire matches together in evaluation, and distinguish an association from a causal explanation.
- What remains uncertain: sampling, subjective labels, independent review and probability calibration.
